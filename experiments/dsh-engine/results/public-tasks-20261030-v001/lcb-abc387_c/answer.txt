## Solution

**Approach:** Count snake numbers ≤ N via digit counting, then answer = `f(R) − f(L−1)`.

For a number of length `d` with leading digit `a` (1–9), every other digit must be in `0..a−1`, giving `a^(d−1)` choices.

`count_leq(N)`:
1. **Shorter lengths** (`2..d−1`): sum of `a^(len−1)` for `a = 1..9`.
2. **Same length, smaller leading digit** `a < n₁`: add `a^(d−1)` each.
3. **Same length, equal leading digit** `a = n₁`: walk the remaining digits left to right. At position `i` with digit `nᵢ`:
   - if `nᵢ > a−1`: all `a` choices are smaller → add `a^(d−i)` and stop;
   - else: add `nᵢ · a^(d−1−i)` (choices `0..nᵢ−1`) and continue;
   - if we reach the end, N itself qualifies → add 1.

Complexity is O(d²) with `d ≤ 19` — instant.
