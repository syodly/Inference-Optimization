# 模型配置与编排校准

V006 的部分事实提示修改没有修复短文校准题的 unknown，不能把提示变化当作成功机制。随后采用 LongBench-v2 的完整长文研究任务，原文约二万至三万四千 Qwen token，并将引擎上限提高到 64K，让集中阅读也有足够上下文。原先 192 token 的证据预算在长文上频繁截断，增加到 768 后截断消失；默认 xhigh 思考也与有限预算不匹配，因此单独对照官方采样和 low 思考强度。固定的四题校准中，推荐 low 配置下分片流程答对三题、集中阅读零题，所有调用均无截断和空输出。该差异只描述本组校准：分片同时改变调用数、总计算量和信息路径，尚不能单独归因为拓扑，后续需要集中反思或相同总计算预算对照。E1 因此固定已校准的分片、low 思考和预算，八题资源压力测试不再混入能力参数变化。完整失败、请求及实际 token 均保留，隐藏答案不进入运行时。

对应配置：`quality-v006.json`、`long-quality-v007.json`、`long-capability-v008.json`、`model-config-v009.json`。
