# v011 前缀命中的核查

单任务预热的 evidence 命中比例 66.6%，八任务为 22.8%，不能直接当作并发导致的缓存损失。逐题核查表明，两轮共同的第一道题在三个子 Session 分别命中 784、784、1568 个 token，完全相同；加入工具延迟后仍相同。八任务其余来源较短，多个共同前缀不足一个缓存块，拉低了总体比例。引擎日志确认该混合注意力模型为对齐 recurrent state，将 attention block 调整到 784 token。/tokenize 逐调用复核的 80 份输入长度全部匹配实际 usage。长文四题中 evidence 共命中 114464/136970 token，约 83.6%，没有抢占，尚无证据说明本组自然工具等待损坏历史复用。需要区分应用历史修改、检查点对齐与真实驱逐，后续保留完整逐请求诊断，不用总体命中率单独归因。
