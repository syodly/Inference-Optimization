# v012：八题长文持久 Session 的工作集压力

本版本先修复 JSON 围栏解析，不改模型、任务清单或必做分支。四题校准共40次调用，来源检查无解析错误，35条引用24条在原文中找到，最终准确率1/4；历史复用114464/139780 token，约81.9%，无抢占。八题自然工具轮次80次调用，准确率5/8，平均169.41秒，evidence命中0，22次抢占，缓存活动占用峰值1.0。加入12±3秒的核验延迟后仍为5/8、平均167.67秒、命中0、5次抢占。延迟后抢占较少，但没有看到任务明显更快；所以不能只优化抢占计数。四题和八题输入不同，不能单独据此认定并发因果，需要在八题上固定工作量并改变派发或Session展开。v014将比较调用上限、回流优先、跨工具Session窗口及后端阶段优先；v015用固定输入/解码配额回放补充归因，仍以完整闭环质量作为最终依据。

## 边界

- 该原型有真实推理、BM25和来源核验；不是DSH完整实现。
- 25%和62.5%的准确率分别来自不同清单，不是并发提高了模型能力。
- v010与v012之间引擎已重启，实际缓存容量从217725变成282532 token；不跨服务直接声称提速。
- 阶段优先与Session窗口都属于现有相关工作覆盖的基线类别，不宣称新颖性。
