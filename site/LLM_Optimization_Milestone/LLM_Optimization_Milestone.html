What Changed Across Phases

每个阶段的核心变化，是系统能够利用的信息和做决策的时间点不断前移。

PHASE 01
从整条请求到 token / phaseServing engine 开始理解迭代级执行、输出长度和 Prefill / Decode 干扰。
PHASE 02
从单请求到静态 application DAG服务端看见跨请求依赖、数据流、应用目标和已知 workflow 的 KV 复用。
PHASE 03
动态 Agent 推理优化的展开同一方向内部从运行时程序状态和工具等待出发，逐步扩展到 workflow 预测、主动资源管理以及 token/block 级 KV 控制。
PHASE 04
复用机制与完整执行成本独立块、跨模型状态与 coding 负载；命中不等于节省计算。
PHASE 05
上下文变化与状态契约生命周期、版本、编辑意图与引擎反馈共同参与决策。
