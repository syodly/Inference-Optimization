5. Reasoning Language Model Inference Serving Unveiled: An Empirical Study

  • 会议：The Fourteenth International Conference on Learning Representations（ICLR 2026）主会
  • 时间：2026 年 4 月 23-25 日；ICLR 2026 完整活动为 4 月 23-27 日
  • 地点：Rio de Janeiro, Brazil
  • 作者：Qi Li, Junpan Wu, Xiang Liu, Yuxin Wang, Zeyu Li, Zhenheng Tang, Yuhan Chen, Shaohuai Shi, Xiaowen Chu
  • 论文链接：ICLR/OpenReview PDF

大概内容

这是一篇 Reasoning LLM serving 的系统性实证研究。论文对比普通 LLM 与长思维链 RLLM，发现 RLLM 具有更高且波动明显的 KV cache 占用、请求运行时间长尾、straggler request、随题目难度变化的执行时间，以及不同任务领域上的性能偏好。

论文提出 ASU 评估框架和 ASU-Perf benchmark，从准确率、服务提供方指标和用户体验指标三个角度评估 serving，并研究权重量化、KV cache 量化、prefix caching、speculative decoding 和 prefill-decode disaggregation 等技术。结果说明一些传统 LLM 优化在 RLLM 上并不总是有效，例如小模型上的 prefix caching 可能降低 serving 性能。

与 Continuum 的关系

两篇论文都涉及 KV cache 与推理服务效率，但研究对象不同：本论文关注单轮或批量 RLLM 长思维链推理的 serving 特征；Continuum 关注 Agent 在 LLM 请求与工具调用之间交替执行时的多轮调度和 KV cache TTL。经核对，本论文正式公开 PDF 的正文和参考文献中均未出现 Continuum，因此它是相关工作，不是 Continuum 的直接引用论文。
