大概内容

论文提出 ACE（Agentic Context Engineering），把 Agent 的上下文看成能够持续演化的结构化“操作手册”，而不是一次性提示词或不断被整体重写的摘要。ACE 使用 Generator、Reflector 和 Curator 三个角色，分别负责生成轨迹、从成功与失败中提取经验，以及把经验增量写入上下文。

其关键设计是增量更新与 grow-and-refine：新经验以细粒度条目加入，旧条目可以局部修改、去重和整理，从而缓解反复重写导致的信息丢失和 context collapse。论文在 AppWorld Agent 任务以及金融、医疗、Text-to-SQL 等任务上进行实验，报告了准确率提升以及适应延迟、rollout 成本下降。

与 Continuum 的关系

论文将 KV cache 复用视为长上下文和上下文适应能够实用部署的重要系统基础，并在参考文献中明确收录 Continuum。但 Continuum 不是 ACE 的实验基线，属于背景性引用。
